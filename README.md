# Element Correction Factor (ECF) Commissioning Tool

A MATLAB App Designer application developed to automate the commissioning and quality assurance workflow for **Optically Stimulated Luminescent Dosimeters (OSLDs)** used in radiation therapy dosimetry.

The application imports OSLD measurement data, calculates **Element Correction Factors (ECFs)** and statistical metrics, including **standard deviation**, and provides graphical visualization to assist with detector commissioning.

This tool was developed to reduce manual calculations, improve consistency, and accelerate the OSLD commissioning process.

---

## Features

- MATLAB App Designer GUI
- Import OSLD measurement data from Excel
- Automatic Element Correction Factor (ECF) calculation
- Standard deviation calculations
- Statistical analysis of OSLD response
- Data visualization

## Background

Optically Stimulated Luminescent Dosimeters (OSLDs) require commissioning before clinical use to account for detector-to-detector sensitivity differences.

This application automates the calculation of **Element Correction Factors (ECFs)** and statistical measurements used during the commissioning process, improving both efficiency and reproducibility.
